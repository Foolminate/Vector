# Issue: In-TUI Evaluation Override

## What to build
Enable triggering Agent 2 evaluations directly from the TUI, including status overrides and an empty-state "Run" button.

## Agent Brief

> *This was generated by AI during triage.*

**Category:** enhancement
**Summary:** Allow users to trigger deep AI evaluations (Agent 2) directly from the TUI, overriding existing statuses and automating the initial run.

**Current behavior:**
Agent 2 evaluations (digests) must be triggered via the CLI (`python -m src.main digest`). There is no way to force a deep evaluation on a specific job from the TUI.

**Desired behavior:**
- "Run Evaluation" button appears in Digest view when no digests exist, triggering `evaluate_all_new`.
- Keybinding `D` forces Agent 2 evaluation on any selected row, regardless of current status.
- Forced evaluations set `last_decision_by = 'human'`.
- Both actions run as non-blocking background workers.

**Key interfaces:**
- **`src/review_tui.py`:** Add "Run" button to Digest View and `D` keybinding.
- **`src/evaluator.py`:** Ensure `evaluate_all_new` and individual evaluation methods are accessible.

**Acceptance criteria:**
- [ ] "Run Evaluation" button appears in Digest view when no digests exist, triggering `evaluate_all_new`.
- [ ] Keybinding `D` forces Agent 2 evaluation on any selected row, regardless of current status.
- [ ] Forced evaluations set `last_decision_by = 'human'`.
- [ ] Both actions run as non-blocking background workers.
