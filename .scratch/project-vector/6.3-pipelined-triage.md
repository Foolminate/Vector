## Parent
PRD: Architectural Refactoring for Deep Modules & Pipelined Intelligence (6.0)

## What to build
Implement the core `AgentPipeline` runner and the `TriageStrategy`. This includes a provider-agnostic `ModelAdapter` and an async queue-based system to process jobs as they stream in.

## Acceptance criteria
- [ ] `ModelAdapter` provides a unified `generate_json(prompt, schema)` interface, abstracting Gemini and prepared for OpenAI/Anthropic.
- [ ] `AgentPipeline` exposes a `push(job_id)` method and a `process_queue()` worker for streaming execution.
- [ ] `SeekCollector` is updated to `push()` job IDs to the pipeline immediately after saving.
- [ ] `TriageStrategy` defines the prompt, schema, and repo transition for the Sorter stage.
- [ ] The system ensures "Rejected" jobs are persisted in the DB (Fix Note 9).
- [ ] The pipeline includes a rate-limiting semaphore to protect LLM providers.
- [ ] Errors in the pipeline are isolated: a failure on one job does not halt the stream.
