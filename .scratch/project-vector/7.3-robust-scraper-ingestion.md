## What to build
Update `SeekParser`, `SeekCollector`, and `JobRepository` to handle data ingestion more robustly. Implement atomic transactions for job upserts and action logging. Update components to use `RawJobData` models for validation. Define and implement specific bot-detection triggers (403, CAPTCHA detection) to halt scraping safely.

## Acceptance criteria
- [x] `SeekParser` updated to return `RawJobData` models.
- [x] `JobRepository.upsert_job` updated to accept `RawJobData` and wrap insertion + logging in a single SQL transaction.
- [x] `SeekCollector` detects 403 status and CAPTCHA keywords; logs `bot_blocked` and halts.
- [x] `SeekCollector.scrape_job_details` logs individual job failures to `audit_log` rather than swallowing them.
- [x] Test coverage for concurrent upserts and mocked bot-detection scenarios.
