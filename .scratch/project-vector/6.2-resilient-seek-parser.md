## Parent
PRD: Architectural Refactoring for Deep Modules & Pipelined Intelligence (6.0)

## What to build
Extract the Seek-specific extraction logic into a pure `SeekParser` module. This module will be responsible for transforming raw HTML and Redux data into structured job objects, isolating the system from DOM changes.

## Acceptance criteria
- [ ] `SeekParser` is a pure module that does not require a live browser session.
- [ ] The parser correctly extracts `published_at` and `expiration_date` (Fix Note 7: Expiry date scraping bug).
- [ ] The parser is resilient to "Salary" or "Location" missing but fails fast on "Title" or "Description."
- [ ] The `SeekCollector` is refactored to use `SeekParser` for all data extraction.
- [ ] A comprehensive test suite for `SeekParser` uses static HTML snapshots of Seek pages.
- [ ] The parser handles catastrophic Redux failures by falling back to DOM scraping or flagging for manual review.
