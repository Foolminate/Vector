# Issue: Background Validity Engine

## What to build
Implement the background validity checking engine with "Clean Sweep" logic and TUI progress tracking.

## Agent Brief

> *This was generated by AI during triage.*

**Category:** enhancement
**Summary:** Implement a background engine using Textual workers to verify if job listing URLs are still active, including smart logic to clean up expired rejections.

**Current behavior:**
The system does not verify if job listings are still live. "Ghost" jobs (deleted but still live) can clutter future scrapes.

**Desired behavior:**
- Async HTTP HEAD check implemented using `httpx` and Textual `@work`.
- "Clean Sweep" logic: Active jobs checked on trigger; Rejected jobs only checked if `expiration_date` < now.
- Expired rejected jobs are automatically marked for deletion.
- Progress indicator (e.g., footer message) displays status of background checks.
- Keybindings `v` (Verify Selected) and `V` (Verify All) trigger checks.

**Key interfaces:**
- **`src/review_tui.py`:** Implement `@work` methods for background checking.
- **`httpx`:** Use for efficient async HEAD requests.

**Acceptance criteria:**
- [ ] Async HTTP HEAD check implemented using `httpx` and Textual `@work`.
