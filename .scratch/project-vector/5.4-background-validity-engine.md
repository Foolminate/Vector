# Issue: Background Validity Engine

## What to build
Implement the background validity checking engine with "Clean Sweep" logic and TUI progress tracking.

## Acceptance criteria
- [ ] Async HTTP HEAD check implemented using `httpx` and Textual `@work`.
- [ ] "Clean Sweep" logic: Active jobs checked on trigger; Rejected jobs only checked if `expiration_date` < now.
- [ ] Expired rejected jobs are automatically marked for deletion.
- [ ] Progress indicator (e.g., footer message) displays status of background checks.
- [ ] Keybindings `v` (Verify Selected) and `V` (Verify All) trigger checks.
