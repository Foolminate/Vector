# Issue: Scaffolding & Configuration

## What to build
Setup the fundamental configuration and persistence layer. This includes the `DOCTRINE.md` file, `SEARCH_CONFIG.yaml`, and the initial SQLite database schema.

## Agent Brief

> *This was generated by AI during triage.*

**Category:** enhancement
**Summary:** Initialize the project's configuration files and SQLite persistence layer.

**Current behavior:**
The project is currently a skeleton with only a `main.py` printing a hello message. There is no configuration or database.

**Desired behavior:**
The project should have a defined "Technical Doctrine" in Markdown, a "Search Configuration" in YAML, and a functional SQLite database for job persistence. A basic CLI should be able to verify the connection to these components.

**Key interfaces:**
- **Technical Doctrine (`DOCTRINE.md`):** A Markdown file with sections for `Must-Haves`, `Hard-Disqualifiers`, and `Weighting-Factors`.
- **Search Configuration (`SEARCH_CONFIG.yaml`):** A YAML file defining a list of `searches` (keywords) and `locations` with priority levels.
- **SQLite Schema (`vector.db`):** 
    - `jobs` table: `id` (PK), `job_title`, `company`, `location`, `url`, `raw_text`, `status` (new/edge/high/rejected), `score`, `rationale`, `analysis_json`, `created_at`.
    - `audit_log` table: `id` (PK), `timestamp`, `action`, `details`.
- **CLI Entry Point:** `main.py` should be updated to handle subcommands (starting with `scrape`, `review`, `digest` as placeholders).

**Acceptance criteria:**
- [x] `DOCTRINE.md` is present and populated with the Scale vs. Toil doctrine.
- [x] `SEARCH_CONFIG.yaml` is present and includes Hamilton, Waikato, and Remote tiers.
- [x] Running a setup script or the main CLI initializes `vector.db` with the correct schema.
- [x] `main.py` responds to a command like `python main.py --help` showing the planned subcommands.
- [x] Automated tests verify that the database can be connected to and the config files can be parsed.

**Out of scope:**
- Implementation of the actual scraper logic.
- Implementation of the AI triage logic.
- Implementation of the Review CLI interaction.
