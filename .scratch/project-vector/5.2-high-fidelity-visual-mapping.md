# Issue: High-Fidelity Visual Mapping

## What to build
Overhaul the `JobItem` widget in the TUI to provide rich visual feedback using emojis and background colors based on status, decision source, and validity.

## Agent Brief

> *This was generated by AI during triage.*

**Category:** enhancement
**Summary:** Enhance the TUI's visual representation of job listings to provide immediate clarity on status, decision source (Robot vs Human), and validity.

**Current behavior:**
The TUI uses a basic list view with minimal visual differentiation between job states. It does not display icons for decision sources or validity status.

**Desired behavior:**
- `JobItem` displays high-fidelity emojis (✅, ❌, ❓, ✨, ⏰, 🤖, 👤) correctly mapping to job state.
- Visual grouping implemented using background colors (e.g., Bright Green for shortlisted, Dim Red for rejected, Gray for expired).
- Urgent items (edge-cases) are visually highlighted with warning colors.

**Key interfaces:**
- **`src/review_tui.py`:** Update `JobItem` class and its `render` or `compose` logic.
- **`Textual` Styling:** Use Textual CSS or inline styles for background colors.

**Acceptance criteria:**
- [ ] `JobItem` displays high-fidelity emojis (✅, ❌, ❓, ✨, ⏰, 🤖, 👤) correctly mapping to job state.
- [ ] Visual grouping implemented using background colors (e.g., Bright Green for shortlisted, Dim Red for rejected, Gray for expired).
- [ ] Urgent items (edge-cases) are visually highlighted with warning colors.
